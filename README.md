## 📥 Instalação

1. Faça download do arquivo `.jar`
2. Coloque em `~/.mindustry/mods/`
3. Reinicie o Mindustry
4. Ative o mod nas configurações

## 🛠️ Compilar

```bash
./gradlew jar
```

O arquivo compilado estará em `advanced-tech.jar`
